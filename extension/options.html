AI Query SDK — Settings checking…

The base path of the SDK inside your application, ending in /ai-sdk.

Required deployment configuration 
ai-sdk:
  security:
    allowed-origins:
      - chrome-extension://<this extension's id>

Only the issued token and its expiry are kept in extension storage. The password is sent once to POST /ai-sdk/auth/token and never written to disk. When the token expires, sign in again.
